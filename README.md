## DLRS
dlrs (pronounced dolores) is a TUI wrapper for yt-dlp designed for quickly downloading videos into folders written in Rust.

This is my first project in Rust therefore some of the code may be ugly, but for the most part I just followed tutorials and used my prior programming experience

## REQUIREMENTS
dlrs requires yt-dlp to be installed and added into your PATH, as it uses yt-dlp to download the videos.

Currently, dlrs is Windows only but Linux & MacOS support is planned to come eventually.
